# Mess Feedback System (Java Swing)

A complete **Java Swing desktop application** that allows users to record, manage, and analyze feedback for a hostel or canteen mess.  
It features data persistence, CSV export, and live statistics — all wrapped in a clean, interactive GUI.

---

## Features

- Add feedback with **Name**, **Roll No**, **Mess**, **Rating**, and **Comments**
- View all entries in a sortable table
- Delete specific feedback
- Persistent storage using **serialization (.ser file)**
- Export all feedback to **CSV**
- Shows **average rating** and total feedback count
- Simple and intuitive UI built using **Java Swing**

---

## Requirements

- **Java JDK 8 or later**
- Works on **Windows / macOS / Linux**
- IDE: IntelliJ IDEA, Eclipse, or any Java compiler
